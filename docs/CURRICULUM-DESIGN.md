# 課程設計說明（經濟學教育家角度）

本文件說明「經濟學園」為何由中一開始、如何切分階段，以及每個階段對應的香港課程與大學經濟學核心。內容依據以下官方文件與課程慣例整理：

- 教育局《公民、經濟與社會課程指引（中一至中三）》（2022），經濟範疇包括資源與經濟活動、理財教育、香港公共財政、香港經濟表現及人力資源、國家經濟與世界貿易、全球化等。[CES 課程指引](https://www.edb.gov.hk/attachment/tc/curriculum-development/kla/pshe/CESCG_c_20240730%20clean.pdf)
- 教育局《經濟課程及評估指引（中四至中六）》。2025/26 學年起中四推行優化安排，適用於 2028 年起 HKDSE；必修部分 10 個課題（A–J），選修部分二選一（單元一：壟斷定價、反競爭行為及競爭政策；單元二：貿易理論之延伸、經濟增長及發展）。[經濟科課程（教育局）](https://amp.edb.edcity.hk/doc/chi/Econ.pdf)
- 考評局 HKDSE 經濟科評核大綱：卷一多項選擇題（必修部分）、卷二甲部短題目（必修）、乙部結構/文章/資料回應（必修）、丙部選修單元。[HKEAA 經濟科](https://www.hkeaa.edu.hk/tc/hkdse/hkdse_subj.html?A1&1&9)

## 1. 為何刪去「學前」與「小學」

數學樂園由學前（數數、10 以內加減）一路到大學；經濟學卻沒有一個對應的「學前／小學經濟學」正規課程。香港的正規經濟學教育起點是：

- **中一至中三**：「公民、經濟與社會」中的理財教育、公共財政、香港經濟表現、國家經濟與世界貿易、全球化等單元；
- **中四至中六**：HKDSE 經濟科（微觀＋宏觀，另加選修單元）。

因此本 app 刪去學前與小學（P.1–P.6）階段，改為由 **中一** 開始，並把中四至中六按 DSE 課程的認知順序分成三年，最後接上大學經濟學主修核心與挑戰區。這樣既保留「由淺入深、逐級解鎖」的學習路徑，又不會出現「小一經濟學」這種不存在的內容。

## 2. 階段切分與理由

| 階段 | 課程依據 | 設計理由 |
|---|---|---|
| 中一 | 公民、經濟與社會（中一）理財教育；本 app 補充基本經濟概念 | 由學生最熟悉的金錢、消費、儲蓄、借貸入手，建立稀少性、機會成本、生產要素等經濟學語言。 |
| 中二 | 公民、經濟與社會（中二）公共財政、香港經濟表現及人力資源 | 由個人理財擴展到公共資源與整體經濟：稅制、預算、GDP、增長、失業、通脹。 |
| 中三 | 公民、經濟與社會（中三）國家經濟與世界貿易、全球化 | 由本地經濟擴展到國家與世界：國際貿易、比較優勢、匯率、關稅、國際收支、經濟體系、發展。 |
| 中四 | DSE 必修 A 基本經濟概念、B 廠商與生產、C 市場與價格 | DSE 微觀的基礎：機會成本與 PPF、廠商成本與利潤、需求供應與均衡、彈性。這是整條 DSE 路線的地基。 |
| 中五 | DSE 必修 D 競爭與市場結構、E 效率、公平和政府的角色；並補要素市場 | 由「市場如何運作」進到「市場結構與政府干預」：完全競爭、壟斷、寡頭、價格歧視、盈餘、稅負、價格管制、外部性、公共財、工資。 |
| 中六 | DSE 必修 F–J（宏觀與國際）＋選修單元延伸 | 宏觀量度與決定、貨幣銀行、宏觀問題與政策、國際貿易與金融、增長與發展。把 DSE 必修與選修單元二的重點一併覆蓋。 |
| 大學 | 大學經濟學主修核心：微觀、宏觀、計量、應用、思想史 | 由 DSE 的圖形與政策分析，提升到模型、最優化、均衡、計量推論與學派脈絡。 |
| 挑戰區 | 跨課題應用與解難 | 不受年級解鎖限制；以多步計算、政策權衡、數據與博弈訓練高階經濟推理。 |

## 3. 教學取捨

1. **先具體後抽象**：中一至中三以生活情境（零用錢、八達通、茶餐廳、網購、政府預算、香港與國家經濟）建立概念；中四起才引入函數、圖形與彈性公式。
2. **計算與概念並重**：每個階段同時有「生成式計算題」（同一題型無限變化）與「概念題庫」（定義、辨認、比較、常見誤解）。概念題不會要求背誦會變動的現實數據。
3. **圖形素養**：供需圖、PPF、AD-AS 以 SVG 呈現，讓學生把文字與圖形連起來；但圖形只輔助，不取代計算與解釋。
4. **政策課題保持學術中立**：最低工資、貿易保護、再分配等課題，呈現主流經濟學的效率與公平取捨、假設與限制，不寫成政治主張。
5. **DSE 用語一致**：需求價格彈性、從量稅、無謂損失、消費者盈餘、生產者盈餘、價格上限/下限、比較優勢、本地生產總值、經常帳、貨幣乘數等，中英對照。
6. **大學階段不假裝是完整學位課程**：只覆蓋主修最核心的入門概念（消費者/廠商理論、福利、博弈、AD-AS/IS-LM、增長、貨幣、計量、公共/國際/金融/發展/思想史），讓學生銜接大學課本，而非取代課本。

## 4. 與數學樂園的對應

| 數學樂園 | 經濟學園 |
|---|---|
| 學前至小六 | （刪去：經濟學沒有對應的正規課程） |
| 中一至中六 | 中一至中三（公民、經濟與社會）＋中四至中六（DSE 經濟） |
| 大學／研究院 | 大學（經濟學主修核心） |
| 挑戰區（奧林匹克題） | 挑戰區（貿易、彈性、宏觀政策、金融、博弈與數據） |

## 5. 資料與界線

- 本 app 的課程大綱是「參考」而非官方課程的完整複製；學校的教學次序與選修安排可能不同。
- 大學階段只覆蓋入門核心，不包含完整計量軟件操作、高等數學證明或各校差異化選修。
- 所有題目由程式生成或由作者撰寫，答案經自動檢查；如發現錯漏，歡迎在專案中修正。
